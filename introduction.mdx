Windows XP Portfolio is a single-page React application that replaces the conventional developer portfolio with a fully interactive Windows XP desktop experience. Visitors land on a simulated XP desktop complete with draggable and resizable windows, a taskbar with a live clock, a Start Menu, and clickable desktop icons — all powered by a central Window Manager context that tracks focus, z-index stacking, minimise state, and URL hash routing so that every open window gets its own shareable link.

<Note>
  This is a **fork-and-customise** project, not an npm package. You clone or fork the repository, swap in your own content, and deploy the static output. There is no `npm install windows-xp-portfolio` — the whole portfolio is the source code.
</Note>

## What it is

The project renders a pixel-faithful Windows XP UI in the browser using React 18 and Tailwind CSS. Every visible element — the teal "Bliss" desktop gradient, the Luna-style window chrome with a coloured title bar, the toolbar-equipped app interiors, the taskbar with its Start button and system clock — is a React component styled entirely with Tailwind utility classes and Lucide icons. No images are required for the chrome itself.

When a visitor double-clicks a desktop icon (or arrives via a URL hash such as `#about`), the `WindowManagerContext` opens the corresponding window, brings it to the front, and updates `window.location.hash` automatically. Closing the last window clears the hash. This makes individual sections of your portfolio bookmarkable and shareable without any router library.

## Key features

- **Draggable and resizable windows** — each window can be freely repositioned and resized on the desktop canvas.
- **Window Manager context** — a single React context tracks all open windows, their z-index stack, focus state, minimise state, and positions.
- **Taskbar** — shows a button for every open window and a live system clock; clicking a button restores or focuses the matching window.
- **Start Menu** — a themed launcher that lists all apps and can be toggled from the taskbar Start button.
- **Desktop icons** — one icon per app rendered on the desktop, launchable by click.
- **URL hash routing** — opening a window sets `#<appId>` in the URL; arriving with a hash pre-opens the matching app.
- **Six built-in apps** — ready-to-customise components covering the most common portfolio sections (see below).

## Who it is for

Windows XP Portfolio is aimed at developers who want a memorable, personality-driven online presence that doubles as a demonstration of their front-end craft. It works especially well as a talking point in interviews or as a fun side-project showcase — visitors instinctively interact with the windows rather than passively scrolling a page.
