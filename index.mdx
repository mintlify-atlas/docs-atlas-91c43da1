Welcome to the **Windows XP Portfolio** — a fully interactive developer portfolio that recreates the look and feel of Windows XP in the browser. Built with React 18, Tailwind CSS, and Lucide icons, it lets visitors explore your work through familiar desktop metaphors: opening windows, clicking desktop icons, and navigating a Start Menu.

## Get started in 3 steps

<Steps>
  <Step title="Fork and clone">
    Fork the repository on GitHub and clone it locally. The project uses Vite and requires Node.js 18+.
  </Step>
  <Step title="Customize your content">
    Edit the app definitions in `components/os/Desktop.js` to add your own name, bio, projects, and resume.
  </Step>
  <Step title="Deploy">
    Run `vite build` and deploy the `dist/` folder to any static host — GitHub Pages, Vercel, Netlify, or Cloudflare Pages.
  </Step>
</Steps>
